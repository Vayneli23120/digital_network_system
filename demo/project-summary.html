核心服务层

25+ 跨领域服务模块，支撑 AI、自动化、监控与通知

🤖
AI Triage + ADK Agents

故障智能分诊、运营研判、管理层摘要生成。Google ADK 驱动的合规审计、健康预测、根因诊断等 5 个专业 Agent

🧠
RAG Engine

基于知识库文档的向量语义检索，pgvector 存储，支持设备手册、故障案例、SOP 文档的智能检索

⚡
Workflow Engine

规则引擎 + 触发器 + 动作执行器。支持定时备份、离线告警、自动创建工单、CPU 限流、合规扫描等自动化规则

📡
Prometheus Connector + SNMP

对接 Prometheus SNMP Exporter 拉取设备指标，SNMP Trap 实时接收 linkDown/linkUp 事件

🔍
Reachability + Health Monitor

ICMP/SSH 持续可达性探测，多因子设备健康评分（温度、故障频率、使用年限、维修频率、日志异常）

📢
Notification Services

多渠道告警分发：SMTP 邮件、企业微信 Webhook、钉钉 Webhook、系统通知中心。统一通知服务编排

📐
Monitor3D + Floor Plan

Three.js 3D 数字孪生引擎，设备拖拽放置、光纤拓扑布线、流量热力图渲染、SNMP 采集健康面板

🔄
Incident Automation + Insights

故障自动处置引擎，事件关联分析、热点链路识别、根因 Top3 推断、影响范围评估
